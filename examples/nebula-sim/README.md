# Nebula Sim

开发客户端的动画演示：末地高空中的暗色三维星云、少量内部星点，以及分叉闪电。
冷色背光与体积自遮挡显出前后云层，闪电短暂照亮附近的尘埃。
固定在云中的冷光核心透过曲折裂隙显露，近景云壁遮挡远光，形成近壁、飞行物体、远处光核的纵深构图。
一个小长方体沿曲线穿行，镜头从斜后上方跟随；前方云气压缩，后方出现逐渐扩散、回填的尾流，部分闪电会落到物体附近。
飞船缩为原几何尺寸的58%，以76度广角观察；船尾约20.7秒航迹在航道层状云幕中推开排空沟槽，两侧形成向外扩散、双涡翻卷并逐渐破碎消散的湍流云脊，近景世界尘埃随相机产生掠过与短拖影。
左上角只显示 JetBrains Mono 的 `Nebula Sim`、`Freq.` 与方框滑条。

在仓库根目录运行（JDK 21，Python 环境安装 `nbtlib==2.0.4`）：

```bash
python3 scripts/nebula-sim.py --world '/path/to/test-world'
```

脚本将存档复制到 `build/nebula-sim/client/saves/nebula-sim`，不修改源存档。
首次运行未指定 `--world` 时使用本仓库已有的 `modules/modelling/run/client/saves/New World` 开发存档。
进入后自动传送至末地 `(0, 512, 0)`。星云实际范围约 `1344 × 768 × 960` 格，中心位于 `(0, 513.62, 576)`。
演示视图使用 Kasuga 跟随相机，从长方体的斜后上方观察千格尺度的云墙；长方体约 `6 × 3 × 17` 格。

- 拖动滑条：0–2 次闪电/秒，默认每 4 秒一次。零频率允许已有闪电自然衰减。
- 每次闪电包含细分主干、分叉和多重回击，约一秒内衰减；频率按整次放电计数。
- 放电同时改变整片体积云的环境散射，局部点光仍保留；暗部和小尺度受光保持差异。
- 在面板外按住鼠标右键拖动：调整第三人称跟随视角。
- `Esc`：退出演示，恢复原维度、位置、视角、游戏模式、飞行与 HUD 状态。
- 手动启动或重启：`/kasuga_nebula`；手动停止：`/kasuga_nebula stop`。

仅支持未开放 LAN 的单人集成服务器。没有实体、真实雷击、声音或地形编辑。
退出游戏时也会在玩家保存之前恢复原状态。异常终止进程不经过正常退出回调。
本示例位于 `contentTesting`，不会包含在正式库的 jar 中。

仿真由公开的 `AnimationTimeline` 以每秒 20 tick 推进；云流动、长方体轨迹、尾流、相机与闪电在同一时钟上插值。
跟随位姿由 `CameraFollowSettings` / `CameraTarget` / `CameraProjection` 生成；不额外渲染一份世界。
物体采用有向盒射线相交，气体在其表面前进行体积积分，以实际透射率合成表面。
尾流使用固定24个船尾历史位置、相邻0.9秒，在尾流横截面正交基上施加向外推移与对称双涡域扭曲，排空中心云气并翻卷两侧压缩云脊，随年龄扩张并在约20秒内逐渐回填消散，不使用直线发光尾迹。
云团使用两种尺度的细胞侵蚀与细胞法向受光，粗略云阴影采样基础密度场；近景侵蚀随距离衰减以减少远景闪烁。
云峡密度与光核均固定在云坐标中。前方压缩弧和尾流边缘增强散射，最终使用 filmic HDR 映射保留亮暗层次。
渲染通过 `RenderShaderDescriptor` 和 `PostProcessGraph` 实现。体积现在以完整分辨率渲染，160段非均匀积分向相机附近分配更多采样；原生 GUI 在其后绘制。
阴影每四次有效采样更新，并在进入云体时重新求取；全分辨率和小尺度侵蚀增加GPU负载。
仅演示启用期间替换末地背景，保持无地形的暗色观测空间；没有修改公共渲染 API。

验证与录制（需 `ffmpeg` 在 PATH）：

```bash
./gradlew :modules:modelling:modelUnitTest --tests 'test.kasuga.modelling.nebula.*'
python3 scripts/nebula-sim.py --test --record-seconds 15
```

产物：`build/nebula-sim/nebula-sim.mp4`、PNG 截图与 `report.json`。
客户端 smoke 使用真实鼠标事件验证滑条，读取实际 RGBA，并检查资源重载、缩放、视角变化、退出/重启/断线清理以及保存后的玩家状态。
暂停时钟后的两组 A/B 像素对比验证长方体确实可见、尾流确实改变云气；录制前恢复默认低频。
另外检查核心开关的实际像素差异，以及闪电最亮帧的白色高光面积，防止放电把整幅画面冲成白屏。
细节和全局闪电另有独立A/B检查；全局闪电必须使至少25%的画面像素发生可观察变化。
录制阶段改用每帧固定1/30秒的唯一动画时钟驱动者，每30帧对应1秒仿真，不因离线渲染耗时改变飞行或闪电速度。普通交互演示仍由20Hz客户端tick驱动；导出30FPS不表示实时渲染可达30FPS。
已验证环境：Apple M3 Max、Java 21、Minecraft 1.21.1、NeoForge 21.1.203、Iris/Sodium 已安装且未开启外部光影包。
其他 GPU、启用外部光影包的结果尚未验证。

字体随资源包提供，许可见 `modules/modelling/src/contentTesting/resources/assets/kasuga_demo/font/OFL-JetBrainsMono.txt`。
